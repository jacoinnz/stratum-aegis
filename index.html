THE MODEL

Four tools. One rule for each: know when you're allowed to use it.

Every tool below is real, independently documented, and imperfect on its own. CU-BOM's job is routing — matching the right tool to the right situation, and refusing to run it when the safeguard fails.

SELF-SERVE

Run it yourself, no facilitator required

Everything on this site is meant to be used without hiring anyone — read it, check the safeguard, run the tool with your own team.

1

Find your situation in the matrix

Match what's actually happening — a launch, a stuck vendor call, a crisis, a leaky funnel — to the tool built for it.

2

Run the safeguard check first

Every tool has a go/no-go condition — a psychological-safety score, an expertise threshold, a time-pressure read. Skipping this is the most common way these tools fail.

3

Copy the template and run it

The playbook has the worksheet, the invite text, and the follow-up email already written — fill in the brackets and send.
